# DataPulse

## E-Commerce Intelligence Platform

**Turn Data Into Better Decisions.**

DataPulse is a data-driven E-Commerce Intelligence Platform built with Python and Streamlit.

It accepts an **EDA-completed, analysis-ready CSV/XLSX/XLS dataset** and transforms it into business analytics, machine-learning predictions, operational intelligence, and actionable recommendations.
